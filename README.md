## Google Gemini in Python Script

## What does this code do? ❓
From your Google Gemini API Key this prodect will use it to start a chat within Python, (if you dont have a Gemini API Key theres proberly public ones idk though)
(Please run the code is Visual Studio Code as thats whats worked best for me but if you have something else that works feel free to use that)

## How to use 💻
Before you start using this prodect you will have to do the command "pip install google-generativeai" also the prodect will attempt to install the package if you already have it or want to install it manually you can. Next once installed it will ask for your name to save as a tempory variable, this is so it can refer to you by name. Then it will ask for your Gemini API Key, the script will script this step if you have inputed it in the code already. Then you will be able to start so feel free to try. if it doesnt work please make sure you have put the API Key in the right place/inputed it right.
